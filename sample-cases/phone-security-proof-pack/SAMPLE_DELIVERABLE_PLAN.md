# Sample Deliverable Plan

## Offer Unit

One phone security proof pack for one scoped device check or post-reset baseline.

## Partner Fit

The phone security operator keeps the client relationship, consent path, device handling, and technical tool execution.

WitnessOps packages agreed non-secret outputs into a client-readable proof pack.

## First Test

Use one demo device or one anonymized low-risk case before using live client material.

## Deliverable Shape

1. Scope and authority note
2. Device and handling summary
3. Tool and method summary
4. Evidence manifest
5. Observed findings
6. Gap register
7. Safe client statement
8. Challenge path

## Safe Claim Posture

The proof pack can say what was checked, what outputs were captured, what was not found by the named method, what remains unproven, and what the client can safely repeat.

It must not turn absence of a finding into absence of compromise.
