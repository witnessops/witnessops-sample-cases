# Sample Case Boundaries

## Purpose

Sample cases demonstrate WitnessOps package mechanics. They are not real customer evidence.

## What sample cases can show

```text
receipt shape
evidence manifest shape
verification result shape
package index shape
report boundary
offline verifier command
workflow outcome semantics
```

## What sample cases cannot show

```text
real source-system honesty
real customer control effectiveness
production key custody
compliance certification
client security posture
```

## Required language

Use bounded language:

```text
This sample package verifies under the provided verifier checks.
This sample workflow outcome is pass, partial, or fail.
```

Avoid unbounded language:

```text
This proves the environment is secure.
This certifies privileged access.
This proves all access is governed.
```
